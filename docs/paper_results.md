## 论文实验设置（Section 5.3 原文要点）

- 温度 `0.2`，最大讨论轮数 `3`，共识阈值 `2/3`（**超过** 2/3 的 agent 答案一致才提前终止）。
- **每轮开始时，从预定义角色集中随机分配角色给所有 agent**。
- **Prompt 模板只在第一轮应用**。
- 进入第三轮时启用"team member optimization"：**挑选 importance 分数最高的两个 agent** 参与辩论。
- 主表对比多种基座模型；消融与分析固定使用 `GPT-4o-mini-2024-07-18`。

> ⚠️ 与官方仓库默认值的差异（影响复现保真度）：
> 官方 `Muty_agent_debate.py` 默认 `ROLES = ["knowledge graphs expert"] * 4`（四个 agent 同一角色），
> 而论文写的是"每轮从预定义角色集随机分配"。官方代码未实现按轮随机；若要严格复现论文需自行实现。
> 另外论文的 team member optimization 依据 **importance 分数**，官方代码则用 **listwise LLM ranker**
> 选 top-2，属于不同的实现路径。

## 其他定性结论

- **Fig. 3**（900 条 ESC 样本）：MRBalance 输入 token 高于 DyLAN，但输出 token 大幅更低，总成本最低。
- **Fig. 4**（团队规模）：4 agents 时正负类准确率相等；4→6 提升 1.2%，6→8 回落 0.7%。
- **6.5 节**：均衡 prompt 偏置把正负样本准确率差距缩小到 5.1%。
- 论文报告 MRBalance 相对 DFP baseline 的 F1 提升：ESC +7.5%、CTB +11.1%。

## 复现对照要点

1. 主设置 = `deepseek-flash`（替代 gpt-4o-mini）+ `positive/normal/normal/negative` + 3 轮 + 2/3 共识。
2. 论文的"每轮随机分配角色"与官方代码"四个 agent 同一角色"不一致，需在汇报中说明取哪一种。
3. 论文指标口径：`R` 为正类召回，`R_neg` 为负类召回，`F1` 由 P 与 `R_pos` 计算，`Acc` 为总体准确率——
   与 `src/mrbalance_replay/evaluation/metrics.py` 的 `pos_recall` / `neg_recall` / `accuracy` 语义一致。
